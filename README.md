<h2>🚀 ¿Qué es vacunacion.info?</h2>

<p>
Aplicación web diseñada para <b>facilitar el seguimiento del calendario vacunal infantil</b> en España, adaptándose a cada comunidad autónoma y enviando recordatorios automáticos.
</p>

<p>
👉 Proyecto orientado a mejorar la adherencia vacunal y combatir la desinformación, con potencial uso tanto para familias como para personal sanitario.
</p>

---

<h2>🎯 Problema que resuelve</h2>

<ul>
  <li>Diferencias entre calendarios vacunales por comunidad</li>
  <li>Falta de recordatorios centralizados</li>
  <li>Dificultad para mantener un seguimiento actualizado</li>
</ul>

<h3>👨‍👩‍👧 Familias</h3>
<ul>
  <li>Evita olvidos con recordatorios automáticos</li>
  <li>Seguimiento completo hasta los 18 años</li>
  <li>Adaptación al cambiar de comunidad</li>
</ul>

<h3>🏥 Personal sanitario</h3>
<ul>
  <li>Consulta del estado vacunal a nivel nacional</li>
  <li>Registro y actualización de vacunas</li>
  <li>Mejora de la continuidad asistencial</li>
</ul>

---

<h2>✨ Funcionalidades</h2>

<ul>
  <li>👶 Gestión de hijos (0–18 años)</li>
  <li>📅 Calendario vacunal por comunidad</li>
  <li>📧 Recordatorios automáticos (30, 14, 7 días)</li>
  <li>🔐 Autenticación completa (login, registro, recuperación)</li>
  <li>🔎 Buscador con autocompletado</li>
  <li>📱 Instalación como PWA</li>
</ul>

<p><b>Panel administrador:</b></p>
<ul>
  <li>Registro de vacunas</li>
  <li>Actualización del calendario</li>
  <li>Eliminación de vacunas obsoletas</li>
</ul>
